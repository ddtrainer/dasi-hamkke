# 다시 함께 — 3D 온라인 반려동물 추모공원

바다 위 벚꽃 섬을 직접 걸어 다니며 반려동물을 추모하는 실시간 3D 웹서비스 (React + TypeScript + Vite + Three.js / React Three Fiber).

## 실행

```bash
npm install
npm run dev          # http://localhost:5173
npm run build        # 타입체크 + 프로덕션 빌드 (dist/)
npx tsx scripts/verify-world.ts   # 지형·경로·충돌·자동이동 헤드리스 검증
```

### 폰에서 미리보기
**사진 올리기까지 테스트하려면 개발 서버(`npm run dev`)가 아니라 완성본 서버를 쓰세요:** `npm run build` 후 `npm run preview` → 터미널의 `Network:` 주소(예: `http://172.30.1.86:4173`). 개발 서버는 폰에서 갤러리/카메라로 나갔다 돌아오면 연결이 끊겼다고 보고 **페이지를 자동으로 새로 불러와** 고른 사진이 사라집니다(완성본에는 이 기능이 없음).

`npm run dev`는 `--host`로 열려 있어서, **PC와 폰이 같은 와이파이**이면 터미널에 표시되는 `Network:` 주소(예: `http://172.30.1.86:5173`)를 폰 브라우저에 입력하면 됩니다. 포트가 사용 중이면 5174처럼 다음 번호로 열리니 터미널에 나온 주소를 그대로 쓰세요. 접속이 안 되면 Windows 방화벽에서 Node.js의 사설/공용 네트워크 허용을 확인하세요. (같은 와이파이가 아닐 때는 Vercel 등에 배포해서 접속)

환경변수가 없으면 **체험 모드**(데이터가 이 브라우저 localStorage에만 저장)로 동작합니다.

### Supabase 연결 (선택)
1. Supabase 프로젝트 생성 → Authentication ▸ Providers ▸ **Anonymous sign-ins** 켜기
2. SQL Editor에서 `supabase/schema.sql` 실행 (테이블, RLS, 비공개 사진 버킷 포함)
3. `.env.example`을 `.env`로 복사하고 `VITE_SUPABASE_URL`, `VITE_SUPABASE_ANON_KEY` 입력

### Vercel 배포
저장소를 Vercel에 연결 → Framework: Vite, Build `npm run build`, Output `dist`, 위 두 환경변수 등록.

## 구조
- `src/world/terrain.ts` — **순수 로직**: 높이맵 지형, 다리/연못/개울 판정, 충돌(원형 콜라이더), 산책로 그래프 + 다익스트라 경로, 분향소 자리 21곳(언덕 위 5곳 포함)
- `src/world/layout.ts` — 나무·꽃·바위·벤치·가로등 결정적 배치(경로·분향소 앞을 피함)
- `src/world/*.tsx` — 지형/바다/폭포 셰이더, 인스턴싱 식생(바람 흔들림), 다리·아치·전망대, 분향소, 절차적 아바타·강아지, 3인칭 카메라(지형·나무 가림 보정)
- `src/lib/api.ts` — 로컬/Supabase 이중 구현, `image.ts` 업로드 정제(형식·5MB 검사, EXIF 제거, 800px 재인코딩), `audio.ts` 절차적 사운드(파도·바람·새·발걸음·음악)
- `src/ui/*` — 입장 화면, HUD, 조이스틱, 분향소/등록 모달, **2D 대체 화면**

## 알려진 한계 / 후속 개선
- 아바타·강아지는 GLB 모델이 아니라 기본 도형으로 만든 절차적 캐릭터입니다. 실제 GLB 교체 + `AnimationMixer` 적용 필요. 참고 이미지만큼의 그래픽 품질에는 아직 못 미칩니다(나무·꽃은 로우폴리).
- 분향소 자리는 21곳 고정. 비공개 분향소는 타인에게 빈 자리로 보이므로 Supabase 모드에서 자리가 겹치면 다음 자리로 재시도합니다.
- 실시간 멀티플레이, 사진 기반 3D 반려동물, 캐릭터 커스터마이징은 범위 밖(후속).
- 번들이 약 1.1MB(three 포함): 코드 분할, GLB 압축(Draco/KTX2), 텍스처 아틀라스 필요.
- 서버 측 이미지 검증(콘텐츠 검사), 신고/관리 기능, 사진 삭제 시 스토리지 정리 필요.
